# Laravel Study Notes

These are my personal study notes, recorded while learning and working with Laravel. They collect the framework concepts I want to understand, practise, and revisit in one place.

Each chapter explains a core idea in beginner-friendly language, then uses practical PHP examples to show how it fits into an application. The examples follow Laravel 13 documentation and assume a working PHP, Composer, and database setup where a chapter needs one.

## How to use these notes

Read the chapters in order and try each example in a small Laravel application. Run the Artisan commands from the project root. Before using a framework feature in a real application, check the current official documentation for the exact version installed in that project.

## Core chapters

1. [Start with Laravel](./chapters/01-start-with-laravel.md) - Install Laravel 13, explore the application structure, and trace an HTTP request.
2. [Routes and controllers](./chapters/02-routes-and-controllers.md) - Define routes, name them, connect controllers, and return responses.
3. [Blade views and layouts](./chapters/03-blade-views-and-layouts.md) - Render Blade templates with layouts, components, loops, and escaped data.
4. [Forms and validation](./chapters/04-forms-and-validation.md) - Accept form input, validate requests, protect web forms, and show errors.
5. [Database migrations and seeders](./chapters/05-database-migrations-and-seeders.md) - Create schema changes and reliable seed data with Artisan.
6. [Eloquent models and relationships](./chapters/06-eloquent-models-and-relationships.md) - Define Eloquent models, mass assignment rules, relationships, factories, and casts.
7. [Queries, scopes, and pagination](./chapters/07-queries-scopes-and-pagination.md) - Build queries, reusable scopes, pagination, eager loading, and transactions.
8. [Authentication and authorization](./chapters/08-authentication-and-authorization.md) - Authenticate users and protect actions with gates, policies, and route middleware.
9. [Middleware and request lifecycle](./chapters/09-middleware-and-request-lifecycle.md) - Filter requests and trace them through the application pipeline.
10. [Service container and dependency injection](./chapters/10-service-container-and-dependency-injection.md) - Resolve dependencies through the service container and understand providers and facades.
11. [Build JSON APIs](./chapters/11-build-json-apis.md) - Return JSON, validate API input, shape resources, and handle HTTP responses.
12. [Files and storage](./chapters/12-files-and-storage.md) - Validate uploads and store or retrieve files with Laravel disks.
13. [Queues, events, and scheduled jobs](./chapters/13-queues-events-and-scheduled-jobs.md) - Move slow work to queues and coordinate events, notifications, and scheduled tasks.
14. [Configuration, sessions, cache, and logs](./chapters/14-configuration-sessions-cache-and-logs.md) - Manage environment configuration, sessions, cache, and useful application logs.
15. [Testing Laravel applications](./chapters/15-testing-laravel-applications.md) - Write focused unit and feature tests and run them with Artisan.
16. [Security and deployment basics](./chapters/16-security-and-deployment-basics.md) - Apply practical security checks and prepare a Laravel application for production.
